# Security Policy

Security fixes are provided for the latest released version of NoteroPDF. Upgrade before reporting a problem that may already be fixed.

Do not open a public issue with vulnerability details. Use GitHub's [private vulnerability reporting form](https://github.com/diyanko/NoteroPDF/security/advisories/new). Include the affected version, operating system, reproduction steps, impact, and any suggested mitigation. Remove Notion tokens, personal file paths, Zotero titles, and Notion page IDs from screenshots or logs.

For ordinary bugs without a security impact, use the public [issue tracker](https://github.com/diyanko/NoteroPDF/issues).
